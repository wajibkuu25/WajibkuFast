Cara Pemesanan

Lima langkah sederhana untuk memesan cetakan

  1. 01

    Pilih Produk

    Pilih bahan cetak dari katalog atau dari kategori layanan.

  2. 02

    Masukkan Ukuran / Jumlah

    Isi panjang dan lebar untuk produk per meter, atau jumlah cetak untuk produk satuan.

  3. 03

    Unggah Desain

    Lampirkan file desain maksimal 2,5 MB, atau kirim menyusul jika belum siap.

  4. 04

    Masukkan Keranjang

    Tambahkan beberapa item sekaligus dalam satu keranjang belanja.

  5. 05

    Checkout & Pantau

    Selesaikan checkout, lalu pantau status pesanan memakai ID pesanan Anda.

Endpoint Web App Google Apps Script Aktif:

https://script.google.com/macros/s/AKfycbw2w-qDPo2ZXp2phIWISlWi0pNciiViEwUaA4NuTaS1o4SvKSfo2QIRwwPTaEc3XJJHpg/exec

Harus berakhiran /exec (bukan link `/edit` Google Sheets).

Buka Google Sheets Database

Checklist 11 Tab Sheet (5 Inti + 6 Banner Member Rewards) — Dapat dibuat otomatis via tombol Inisialisasi:

  • Users: User_ID, Nama, No_WA, Email, Role, Alamat, Password, Status_Akun, Token_Version, OTP_Token, OTP_Expires_At
  • Produk: Produk_ID, Nama_Produk, Kategori, Tipe_Hitung, Harga_Dasar, Satuan, Min_Order, Status
  • Finishing: Finishing_ID, Nama_Finishing, Tipe_Biaya, Tambahan_Harga, Keterangan, Status
  • Pesanan: Order_ID, Tanggal, User_ID, Status_Order, Total_Tagihan, Bukti_Bayar, Status_Bayar, Catatan (+ kolom Harga_Kotor, Saldo_Dipakai, Reward)
  • Detail_Pesanan: Detail_ID, Order_ID, Produk_ID, Panjang_m, Lebar_m, Qty, Finishing_ID, File_Desain, Keterangan_Item, Subtotal
  • Banner Member Rewards: Member_Profiles, Wallet_Accounts, Wallet_Transactions, Withdrawal_Requests, System_Settings, Biaya_Tambahan
